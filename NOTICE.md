# Attribution and independence

The `shlepa-quality` skill, its helper scripts and templates are original work assembled for ShlepaGame. They are inspired by general workflow techniques described in:

1. Studio Igor, `game-exp-skills`, https://github.com/studioigor/game-exp-skills — sequential evidence-led A/B review and cost-awareness.
2. Studio Igor, `studioigor-skill`, https://github.com/studioigor/studioigor-skill — playable mechanic gyms and game-first acceptance; repository carries an MIT License.
3. Studio Igor, `gamestudio`, https://github.com/studioigor/gamestudio — risk-weighted testing and lean worker economics; repository carries an MIT License.

No upstream source files, licensed graphics or third-party skills are vendored in this package. This package is not an upstream fork. `publish-github.sh` separately asks the authenticated user's GitHub CLI to create **real forks** of those upstream projects. Any fork retains its original upstream licensing and attribution.

**ref2game is deliberately not included, forked, installed, changed or modified.**

The originally-authored `shlepa-quality` files in this package are released under MIT. The following license applies to those original files only.
